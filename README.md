# Email_Bomber

Email Bomber is a Python-based application that allows users to send multiple emails with attachments to multiple recipients using the SMTP protocol. The application is built using Tkinter for the GUI and supports sending emails securely with an email app password.

## Features
- Send multiple emails to multiple recipients.
- Attach multiple files.
- Uses the SMTP protocol with TLS encryption.
- User-friendly GUI built with Tkinter.

## Requirements
Ensure you have the following installed before running the project:
- Python 3.x
- Required dependencies (install using the command below):
  ```sh
  pip install smtplib tkinter email
  ```

Usage
-----

1.  Clone the repository:
    
    ```sh
    git clone https://github.com/NAMPALLY-PRANAY/Email-Bomber.git
    ```
    
2.  Navigate to the project directory:
    
    ```sh
    cd Email-Bomber
    ```
    
3.  Run the application:
    
    ```sh
    python email_bomber.py
    ```
    

Configuration
-------------

*   Replace `SENDER_EMAIL` with your Gmail address.
*   Generate an **App Password** from your Google Account security settings and replace `APP_PASSWORD` in the code.
